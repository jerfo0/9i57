未来我觉得会出现一大批 FDE 和 Agent 搭建工程师职业。其实 FDE 就涵盖了 Agent 的内容，主要做的也是 Agent 的工作，这种工作可能不是短期的，而是需要长期去调优、去优化的，不断地针对性调整，一方面是让结果更好，一方面是让成本更低，而这些也会随着业务变化而变化。

## Agent 依赖优质数据库和知识库

Agent 会比较依赖优质的数据库，依赖完善正确的知识库，这些只能来源于企业自身。如果这两个方面做得不好，那么出来的结果也会不同。

所以实际上 FDE 不是需要专才，而是需要对整体有把控、对整体有了解，同时能分析出好结果和差结果是怎么产生的、是什么影响的。感觉可能更像一个管理岗——要让团队更好地协作、更快地产出结果，以及更恰当调度企业的资源。

## 普通人入局AI行业最好的方式

我觉得这也是普通人入局 AI 行业最好的方式。不会有那么多人能进 AI 公司，不会那么多人去做 AI 公司的数据标注，但 FDE 的岗位将会很多。因为企业的业务和流程不同，我感觉以后几乎每个公司都会有 1-2 个，甚至是更多的 FDE 从业人员。

而且我感觉薪资会比现在的管理层更高，因为做出好的 Agent 它可以全年无休止地工作，而且没有任何其他的劳务风险。当然我也确信不是所有工作都会被 AI 替代。

## AI编程已经成熟，FDE是下一个趋势

现在 AI 普及比较流行的是编程在企业中的运用，现在这个已然非常成熟了。现在自己写代码的程序猿越来越少了，而且不懂写代码的人，也可以出一系列软件和产品了。这也是 AI 在企业端营收最多的一块。

未来的一块就是 FDE，这个可能比 AI 编程要难得多，需要专业的人也多得多，但这注定是一个趋势。AI 编程刚出来的时候，也有很多程序猿吐槽、嘲笑，但现在都默认了，少不了 AI 编程了。

所以多学学 FDE 吧，多学学 Agent 吧，多学学是绝对没错的。
