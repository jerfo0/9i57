今天研究了很多东西，把碎碎念的博客转移到国内了。

用的是阿里云的一套：OSS（对象存储）放静态文件，CDN 用来优化提速，RAM 用来给 GitHub 上的上传动作分配权限。一套配下来，现在碎碎念的访问稳定性应该会高很多。

## 之前的毛病在哪

原来碎碎念是直接访问 GitHub 的。它是国外的服务器，访问起来总也不是非常稳定，时不时就抽一下。

## 成本这块

OSS 和 CDN 都是按量收费的，不过应该不大，静态博客这种用量是完全够用的。

可能比较麻烦的是 HTTPS 证书，估计要按季度去续约吧。
